# 电脑端前端优化记录

本轮范围：电脑浏览器中的后台页面、表格、表单、弹窗、看板及聊天工作区。未新增手机端交互。

## 公共组件

- 新增 `app/static/css/components.css`，在页面自定义样式之后加载，统一按钮尺寸、字号、圆角、表单边框、焦点、分页、工具栏和弹窗底栏。
- 修正 Layui 生成表格的单元格重复内边距，操作按钮保持单行，宽表由表格内部滚动承载；不通过隐藏按钮处理溢出。
- 弹窗限制在当前工作区内，内容可滚动，保存/取消底栏独立布局；底部下拉菜单根据滚动区域空间调整展开方向。
- 为表单控件关联标签，为图标按钮和行操作补充可访问名称及键盘操作。弹窗支持焦点约束、关闭后焦点恢复。
- 公共增强脚本延迟到文档主体可用后初始化，避免页面加载时观察器报错。

## 页面修正

- 主框架：去掉框架默认的 44px 底部预留，统一导航选中颜色。
- 模型引擎：只有默认模型显示“系统默认”；编辑/删除图标补充文字说明；测试对话输入区随弹窗高度调整。
- 深度采集：修正双栏收缩、搜索按钮换行及标签页滚动区高度。
- 问数主页、协作群聊：聊天区使用工作区完整高度，输入框可收缩，发送区保持可见；长文本、代码和表格在消息内处理。
- 数智大屏、智能舆情：调整布局切换宽度，避免普通笔记本的 iframe 工作区过早变成松散单列。
- 注册：补齐首次渲染所需的 error 参数，修复 GET /register 报错。
- 导出页：加载公共基础变量，修正原本未定义的间距变量。

## 验证结果

- 1366×768 和 1920×1080：实际后台框架内逐页检查 14 个列表，页面横向溢出为 0，已加载行的操作按钮裁剪为 0。
- 1280×720：复核 10 个主要列表，以及模型、瞭望、深度采集、问数、群聊和图表页。
- 打开并检查 9 类通用新增弹窗，另外复核模型新增/测试、权限配置、成员邀请、会话详情、对话详情及采集任务弹窗。
- 检查问数和群聊输入区底边与工作区高度一致；模型测试输入区完整位于弹窗内。
- 28 个模板编译通过，公共 JavaScript 语法检查通过。
- `tests/test_frontend_pages.py`：28 个页面请求和公共资源检查通过，全部使用临时数据库副本。

回归命令：

```bat
conda activate insight_agent
python -m unittest discover -s tests -p test_frontend_pages.py -v
node --check app/static/js/base.js
```

验证未发送真实模型请求、执行外网采集或更改原始业务数据。预览图见 [电脑端效果](frontend-desktop.png)。

启动原项目后按 Ctrl+F5 刷新页面即可加载新样式。

## 2026-10-21：地图与表单修复

- 数智大屏与舆情页改用本地 ECharts、词云组件；地球改用本地真实地理贴图，去掉远程高度图和星空资源。
- 修正热点高度映射，避免标记悬浮在球体之外；新增平面视图、地区定位、重置视角，以及 WebGL 不可用时的平面回退。
- 地图信息栏独立于地图画布，调整容器尺寸监听；画布图表颜色改为可解析的 HEX/RGBA。
- 公共编辑表单统一为顶部标签，补齐必填标记与校验，长表单保留独立滚动区及保存栏。
- 弹窗内容插入后统一初始化 Layui 表单，修复请求方法、状态等下拉框不显示。
- 接口请求头与参数、技能生成补充提示改为折叠项；数字员工采用分组布局及原生多选卡片，修复技能标题直接显示 HTML 的问题。
- 使用临时数据库副本在 1280×720 浏览器检查地图、平面切换、地区选择、接口表单和员工表单；未提交真实业务数据或调用模型。
- 全部模板编译及修改的 JavaScript 语法检查通过，现有 6 项页面和接口测试通过。
- 预览：`frontend-form-optimized.png`。

## 深度采集工作台改版

- 替换原来的三组数据库表格与固定 55% 分栏，使用以标题、摘要为中心的文章列表。默认列表占满内容区，选择文章后才展开阅读区；较窄工作区改为侧边抽屉。
- 来源、关键词、时间降为辅助信息，移除重复的逐行采集按钮与 ID 列。选中资料后显示批量操作栏，采集进度独立展示，可停止后续队列。
- 任务管理改成任务列表和独立配置表单，基础字段分组、高级配置折叠，保留新建、编辑、删除、分页功能。
- 修复资料检索先分页后过滤的问题，支持来源筛选、摘要检索及任务名称/地址搜索。
- 正文与摘要使用文本节点显示，原 HTML 内容降为纯文本阅读，保留配图及原文入口。
- 浏览器在 1280×720 独立页面及带导航的约 1048px 工作区检查列表、预览、批量选择、任务保存和已有成功结果的正文读取；使用临时数据库副本，未执行新的外网采集。
- 新增跨页检索回归检查，全部 7 项现有及新增测试通过；模板编译和页面 JavaScript 语法检查通过。
- 截图：`deep-collect-redesign.png`、`deep-collect-reader-redesign.png`、`deep-collect-task-redesign.png`。
