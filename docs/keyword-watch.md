# 舆情洞察：自定义关键词监测

页面 `/sentiment` 以个人关注词库为主要入口。输入关键词后选择采集起止日期和“任意一个/全部关键词”，点击“保存并匹配”。支持中文逗号、顿号、英文逗号、分号、换行分隔，也可仅保存词库或删除全部关键词后保存。

支持起止日期范围（包含结束日期当天），提供今天、近7天、本月快捷范围。默认起止日期均为北京时间今天。匹配范围为新闻标题、摘要和最新成功提取的正文；不匹配对话记录。大小写不敏感，按字面包含匹配，不做正则、同义词扩展或模型推断。百分号、下划线均为普通字符。命中新闻显示匹配词、对应片段、高亮、来源和原文链接，按采集时间倒序分页。

关键词可以标记为“关注词”“风险词”“问题词”，标签由用户设置。阶段概览显示匹配新闻数、已命中风险词和问题词的数量，以及每个关键词关联的新闻篇数；统计覆盖整个查询结果，不受当前分页影响。

每个用户最多 100 个关键词，每词最多 40 字。词库以用户 ID 隔离保存于 `system_configs`，不需要新增数据库表。查询本身不写入旧风险报告，也不调用外部模型；原有固定规则统计放在可展开的历史区域。

## 页面调用接口

沿用登录认证与 XSRF 校验。POST 支持 JSON，也支持表单参数；JSON 调用需携带 `X-XSRFToken` 请求头和当前登录 Cookie。

读取个人词库与默认日期：

```http
GET /api/sentiment?action=watchlist
```

保存或清空个人词库：

```json
{"action":"save_watchlist","keywords":["投诉","数据泄露"],"levels":{"投诉":"问题词","数据泄露":"风险词"}}
```

查询新闻：

```json
{
  "action":"match_news",
  "keywords":["投诉","数据泄露"],
  "start_date":"2026-10-01",
  "end_date":"2026-10-22",
  "mode":"any",
  "page":1,
  "limit":12
}
```

以上 POST 发送至 `/api/sentiment`。`keywords` 可传数组或分隔文本；省略时使用当前用户已保存的词库。`mode` 为 `any` 或 `all`，`limit` 为 1–50。查询不会覆盖已保存的词库。

响应 `data` 包含 `items`、`count`（匹配总数）、`scanned_count`（阶段内采集总数）、起止日期、时区、keyword_stats（全结果关键词命中统计）与分页信息。每条新闻包含 `matched_keywords` 和带字段名的 `passages`。没有命中时返回空列表，不用历史新闻补位。

验证：

```text
python -m unittest discover -s tests -p test_keyword_watch.py -v
```
