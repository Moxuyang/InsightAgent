使用指南

技能系统使用指南

function_call 外部API调用（真实请求）

真实发起HTTP请求调用外部API，适合查词典、查百科、查天气、查数据、翻译等需要实时数据的任务。

1API地址中用 {query} 占位，系统自动替换为用户输入
2GET请求：URL加参数 ?word={query}；POST请求：在请求体模板中用 {query}
3响应字段：写JSON路径，如 data 或 data.result.content

📌 适合场景：英语词典、百科查询、天气查询、数据分析、AI对话API

skill.md 提示词模板

为数字员工预设回复模板和行为规则，适合客服、咨询、报告生成、专业分析等对话型任务。

1在 description 中描述技能用途和规则
2在 execute_code 中写入 SYSTEM_PROMPT 模板
3数字员工回复时会按模板风格输出

📌 适合场景：专业客服、格式报告、翻译润色、代码审查、数据分析建议

🚀 推荐：使用「AI 智能生成」快速创建技能
1选 AI 模型 → 选技能类型 → 填分类 → 用自然语言描述需求
2点击「AI 智能生成」，AI 自动填写所有表单字段
3检查并修改 AI 生成的内容（尤其是 API 地址和响应路径）
4保存 → 在「数字员工管理」中把技能绑定到员工 → 在群聊中 @员工 即可使用
